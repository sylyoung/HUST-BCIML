# EA-FBMSNet

**Axis:** Network (backbone) &nbsp;·&nbsp; **Paradigm:** MI &nbsp;·&nbsp; **Dataset:** BNCI2014001 (cross-subject LOSO)

**Stage configuration:** `EA · no-aug · FBMSNet · Linear · ERM`

## Mechanism
The archived port applies fixed sub-band kernels, mixed-scale temporal convolution, depthwise spatial filtering and segmented log-variance aggregation before the shared head.

## Provenance
- **Paper / source:** K. Liu et al., IEEE Trans. Biomed. Eng., 2023; doi:10.1109/TBME.2022.3193277
- **Implementation:** Legacy non-equivalent adaptation of the authors' implementation (https://github.com/Want2Vanish/FBMSNet). The official generator applies a causal Chebyshev-II filter bank before the network; this port uses a finite centered zero-phase approximation after the benchmark-wide 8--32 Hz prefilter, so its nominal 4--8 and 32--40 Hz branches do not receive the original raw-band content. The constrained classifier and center-loss training are replaced by the shared Linear head and cross-entropy, and the effective benchmark dropout is 0.25. This row is pending a separately named compliant implementation and remeasurement.
