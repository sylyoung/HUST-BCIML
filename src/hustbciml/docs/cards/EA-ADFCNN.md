# EA-ADFCNN

**Axis:** Network (backbone) &nbsp;·&nbsp; **Paradigm:** MI &nbsp;·&nbsp; **Dataset:** BNCI2014001 (cross-subject LOSO)

**Stage configuration:** `EA · no-aug · ADFCNN · Linear · ERM`

## Mechanism
Two parallel spectral-spatial pathways at different temporal scales are fused by self-attention. The shared Linear head maps the resulting features to benchmark classes.
