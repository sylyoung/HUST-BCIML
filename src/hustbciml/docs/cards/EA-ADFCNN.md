# EA-ADFCNN

**Axis:** Network (backbone) &nbsp;·&nbsp; **Paradigm:** MI &nbsp;·&nbsp; **Dataset:** BNCI2014001 (cross-subject LOSO)

**Stage configuration:** `EA · no-aug · ADFCNN · Linear · ERM`

## Mechanism
Two parallel spectral-spatial pathways at different temporal scales, fused by a self-attention module.

## Result — 3 seeds (1, 2, 3)

| Metric | Value |
|---|--:|
| Accuracy (mean ± std across seeds) | 72.17 ± 1.53 |
| Δ vs baseline (EA-EEGNet, 72.07) | +0.10 |
| Reference range (expected band) | 67–77 |

Accuracy is the mean over seeds; ± is the standard deviation *across* seeds (a reproducibility figure, not the cross-subject spread). The reference range is the published / expected band on this dataset.

## Provenance
- **Paper / source:** W. Tao et al., IEEE Trans. Neural Syst. Rehabil. Eng., 2024; doi:10.1109/TNSRE.2023.3342331
- **Implementation:** Ported from the authors' implementation (https://github.com/UM-Tao/ADFCNN-MI) onto the Backbone ABC: the classification head is dropped so the shared Linear head produces the logits, and the feature width is measured by a construction-time dummy forward so the same file runs on any (channels, samples) dataset. Deviations are listed in the module docstring of src/hustbciml/algorithms/models/ADFCNN.py; see it before quoting this row against the paper's own number.
