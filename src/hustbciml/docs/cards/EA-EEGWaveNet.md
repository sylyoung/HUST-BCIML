# EA-EEGWaveNet

**Axis:** Network (backbone) &nbsp;·&nbsp; **Paradigm:** MI &nbsp;·&nbsp; **Dataset:** BNCI2014001 (cross-subject LOSO)

**Stage configuration:** `EA · no-aug · EEGWaveNet · Linear · ERM`

## Mechanism
Five retained scales from a depthwise temporal downsampling cascade are each processed by a two-convolution feature block, pooled and fused by the released feature MLP.

## Provenance
- **Paper / source:** P. Thuwajit et al., IEEE Trans. Ind. Inform., 2022; doi:10.1109/TII.2021.3133307
- **Implementation:** Adapted from the authors' released implementation (https://github.com/IoBT-VISTEC/EEGWaveNet). The feature extractor follows the released code: six depthwise kernel-2/stride-2 convolutions and two regular kernel-4/stride-1 convolutions per retained scale. The paper prose describes a different regular-convolution stride pattern, so this row claims released-code fidelity only. Its valid convolutions require at least 448 input samples, and the benchmark replaces the final class layer with the shared Linear head.
