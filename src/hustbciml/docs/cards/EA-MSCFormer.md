# EA-MSCFormer

**Axis:** Network (backbone) &nbsp;·&nbsp; **Paradigm:** MI &nbsp;·&nbsp; **Dataset:** BNCI2014001 (cross-subject LOSO)

**Stage configuration:** `EA · no-aug · MSCFormer · Linear · ERM`

## Mechanism
Three parallel multi-scale temporal-convolution branches whose features are fused and passed to a transformer encoder.
