# MVCNet

**Axis:** Network (backbone) &nbsp;·&nbsp; **Paradigm:** MI &nbsp;·&nbsp; **Dataset:** BNCI2014001 (cross-subject LOSO)

**Stage configuration:** `EA · multi-view aug · IFNet · Linear · MVCNet (CVC + CMC contrastive)`

## Mechanism
Multi-View Contrastive Network is a dual-branch network: an IFNet backbone (an interactive frequency-domain CNN) trained with multi-view augmentation and cross-view (CVC) plus cross-modal (CMC) supervised-contrastive losses alongside classification. At inference only IFNet and the shared Linear head run. It changes the backbone, the learning objective and the batch size together, so it carries an "also varies" note; its values are the documented three-seed legacy measurements, outside the corrected five-seed campaign.
