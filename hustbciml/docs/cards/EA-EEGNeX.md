# EA-EEGNeX

**Axis:** Network (backbone) &nbsp;·&nbsp; **Paradigm:** MI &nbsp;·&nbsp; **Dataset:** BNCI2014001 (cross-subject LOSO)

**Stage configuration:** `EA · no-aug · EEGNeX · Linear · ERM`

## Mechanism
A purely convolutional EEGNet variant that replaces the separable temporal convolutions with a stack of dilated convolutions for a wider receptive field.

## Result — 3 seeds (1, 2, 3)

| Metric | Value |
|---|--:|
| Accuracy (mean ± std across seeds) | 74.61 ± 0.92 |
| Δ vs baseline (EA-EEGNet, 72.07) | +2.54 |
| Reference range (expected band) | 69–79 |

Accuracy is the mean over seeds; ± is the standard deviation *across* seeds (a reproducibility figure, not the cross-subject spread). The reference range is the published / expected band on this dataset.

## Provenance
- **Paper / source:** X. Chen et al., Biomed. Signal Process. Control, 2024; doi:10.1016/j.bspc.2023.105475
- **Implementation:** Ported from the authors' implementation (https://github.com/chenxiachan/EEGNeX) onto the Backbone ABC: the classification head is dropped so the shared Linear head produces the logits, and the feature width is measured by a construction-time dummy forward so the same file runs on any (channels, samples) dataset. Deviations are listed in the module docstring of hustbciml/algorithms/models/EEGNeX.py; see it before quoting this row against the paper's own number.
