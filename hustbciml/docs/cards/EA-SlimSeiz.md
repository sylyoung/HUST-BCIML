# EA-SlimSeiz

**Axis:** Network (backbone) &nbsp;·&nbsp; **Paradigm:** MI &nbsp;·&nbsp; **Dataset:** BNCI2014001 (cross-subject LOSO)

**Stage configuration:** `EA · no-aug · SlimSeiz · Linear · ERM`

## Mechanism
A lightweight multi-branch 1D-convolution feature extractor paired with a single Mamba selective-state-space mixer; originally a seizure-prediction network.

| Accuracy (mean ± std across seeds) | 69.65 ± 0.42 |
| Δ vs baseline (EA-EEGNet, 72.07) | -2.42 |

Accuracy is the mean over seeds; ± is the standard deviation *across* seeds (a reproducibility figure, not the cross-subject spread). The reference range is the published / expected band on this dataset.

## Provenance
- **Paper / source:** G. Lu et al., IEEE Int. Symp. Circuits Syst., 2025; doi:10.1109/ISCAS56072.2025.11043364
- **Implementation:** Ported from the authors' implementation (https://github.com/guoruilu/SlimSeiz) onto the Backbone ABC: the classification head is dropped so the shared Linear head produces the logits, and the feature width is measured by a construction-time dummy forward so the same file runs on any (channels, samples) dataset. Deviations are listed in the module docstring of hustbciml/algorithms/models/SlimSeiz.py; see it before quoting this row against the paper's own number.
