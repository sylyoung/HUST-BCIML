# EA-CTNet

**Axis:** Network (backbone) &nbsp;·&nbsp; **Paradigm:** MI &nbsp;·&nbsp; **Dataset:** BNCI2014001 (cross-subject LOSO)

**Stage configuration:** `EA · no-aug · CTNet · Linear · ERM`

## Mechanism
An EEGNet-style convolutional patch embedding feeding a transformer encoder.

## Result — 3 seeds (1, 2, 3)

| Metric | Value |
|---|--:|
| Accuracy (mean ± std across seeds) | 73.97 ± 0.80 |
| Δ vs baseline (EA-EEGNet, 72.07) | +1.90 |
| Reference range (expected band) | 65–75 |

Accuracy is the mean over seeds; ± is the standard deviation *across* seeds (a reproducibility figure, not the cross-subject spread). The reference range is the published / expected band on this dataset.

## Provenance
- **Paper / source:** W. Zhao et al., Sci. Rep., 2024; doi:10.1038/s41598-024-71118-7
- **Implementation:** Ported from the authors' implementation (https://github.com/snailpt/CTNet) onto the Backbone ABC: the classification head is dropped so the shared Linear head produces the logits, and the feature width is measured by a construction-time dummy forward so the same file runs on any (channels, samples) dataset. Deviations are listed in the module docstring of hustbciml/algorithms/models/CTNet.py; see it before quoting this row against the paper's own number.
