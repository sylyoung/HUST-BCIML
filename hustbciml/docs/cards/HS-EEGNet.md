# HS-EEGNet

**Axis:** Augmentation &nbsp;·&nbsp; **Paradigm:** MI &nbsp;·&nbsp; **Dataset:** BNCI2014001 (cross-subject LOSO)

**Stage configuration:** `Identity · HS · EEGNet · Linear · ERM`

## Mechanism
Splices the left- and right-hemisphere channels from two same-class trials into a new trial, exploiting motor-imagery lateralization. An electrode-space transform, run on unaligned trials.

## Result — 3 seeds (1, 2, 3)

| Metric | Value |
|---|--:|
| Accuracy (mean ± std across seeds) | 64.99 ± 0.61 |
| Reference range (expected band) | 60–70 |

Accuracy is the mean over seeds; ± is the standard deviation *across* seeds (a reproducibility figure, not the cross-subject spread). The reference range is the published / expected band on this dataset.

## Provenance
- **Paper / source:** Y. Pei et al., Front. Hum. Neurosci., 2021; doi:10.3389/fnhum.2021.645952
- **Implementation:** Implemented directly from the cited paper against the Augmenter ABC (hustbciml/algorithms/augmenters/); no third-party code vendored. The augmenter is the only stage that differs from the EA-EEGNet baseline.
