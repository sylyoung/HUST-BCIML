# EA-EEGWaveNet

**Axis:** Network (backbone) &nbsp;·&nbsp; **Paradigm:** MI &nbsp;·&nbsp; **Dataset:** BNCI2014001 (cross-subject LOSO)

**Stage configuration:** `EA · no-aug · EEGWaveNet · Linear · ERM`

## Mechanism
A cascade of depthwise Conv1d layers repeatedly halves the sampling rate to extract multiscale temporal features; originally a seizure detector.

## Result — 3 seeds (1, 2, 3)

| Metric | Value |
|---|--:|
| Accuracy (mean ± std across seeds) | 66.64 ± 1.44 |
| Δ vs baseline (EA-EEGNet, 72.07) | -5.43 |
| Reference range (expected band) | 62–72 |

Accuracy is the mean over seeds; ± is the standard deviation *across* seeds (a reproducibility figure, not the cross-subject spread). The reference range is the published / expected band on this dataset.

## Provenance
- **Paper / source:** P. Thuwajit et al., IEEE Trans. Ind. Inform., 2022; doi:10.1109/TII.2021.3133307
- **Implementation:** Ported from the authors' implementation (https://github.com/IoBT-VISTEC/EEGWaveNet) onto the Backbone ABC: the classification head is dropped so the shared Linear head produces the logits, and the feature width is measured by a construction-time dummy forward so the same file runs on any (channels, samples) dataset. Deviations are listed in the module docstring of hustbciml/algorithms/models/EEGWaveNet.py; see it before quoting this row against the paper's own number.
